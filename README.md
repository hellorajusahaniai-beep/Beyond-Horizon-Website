# Beyond Horizon — Premium Marketing Agency Website

Official website and digital portfolio for **Beyond Horizon Marketing Agency**.

## 🚀 Overview
- **Visual Aesthetic**: Pure black minimalist editorial design with typography, smooth canvas scrubbing, and micro-animations.
- **Performance**: High-efficiency WebP image frame sequences with zero-blocking progressive stream loaders and WCAG AA compliance.
- **Pages**:
  - `index.html` — Landing page with hero stage cross-dissolves, case studies, services, testimonials, FAQ accordion, and inquiry form.
  - `pricing.html` — Standalone transparent pricing and bundled growth packages.
- **Integrations**: Direct Google Sheets & Apps Script backend integration for contact inquiries.
- **Deployment**: Configured for instant deployment on Netlify with custom `_headers` and `_redirects`.

---

## 🛠️ Tech Stack
- **HTML5 & CSS3** (Vanilla CSS with design tokens & responsive fluid typography)
- **JavaScript (ES6+)** (Canvas 2D rendering, IntersectionObserver, requestIdleCallback progressive loader)
- **Netlify Ready** (`_headers` and `_redirects`)
